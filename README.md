# Glava — prezentacija

Statična stranica sa prezentacijom proizvoda Glava, organizera sa AI-jem za advokatske kancelarije u Srbiji. Objavljuje se preko GitHub Pages iz grane `main`.

- `index.html`, `style.css`, `app.js` — stranica, bez koraka izgradnje;
- `img/` — snimci ekrana iz demo instalacije sa izmišljenim podacima.

Tabela poređenja i izvori nalaze se u `app.js` (nizovi `ROWS` i `SOURCES`); stanje na dan 07.11.2026.

Lokalni pregled:

```bash
python3 -m http.server 8020
```
